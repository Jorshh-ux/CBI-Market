# Scope — CBI Market

//Problema
A veces al cliente le cuesta elegir qué producto comprar entre tantas opciones.

//Usuario

* Merchant: configura el cuestionario desde Shopify.
* Cliente: responde las preguntas y recibe recomendaciones.

// Propósito

Ayudar al cliente a encontrar productos que se adapten mejor a lo que busca.

//Qué incluye el MVP

* App de Shopify.
* Cuestionario configurable.
* Productos reales de la tienda.
* Filtros para encontrar candidatos.
* IA para elegir y explicar las recomendaciones.
* Recomendación de 1 a 3 productos.

//Qué queda fuera

* Publicación en Shopify App Store.
* Billing y planes.
* Analytics avanzado.
* Multiidioma.
* Embeddings o vector database.
* Personalización profunda por industria.
